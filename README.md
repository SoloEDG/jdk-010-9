# LUMEN 光学实验室

二维几何光学实验台：光程追迹、光程差与飞秒级飞行时间分析。

安装依赖：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`，生产构建：`npm run build`。

测试：`npm test`（`node:test` + `tsx`），覆盖飞行时间、脉冲列、重合判定、误差边界与撤销。

Docker 启动：`docker compose up --build`，访问 http://localhost:18110 。

## 时间模型

所有距离单位为 **mm**，所有时间单位为 **ps**，场景共享同一个时间零点 `t = 0`。

- 真空光速 `c = 0.299792458 mm/ps`（`src/shared/timing.ts`）。
- 飞行时间 `t = OPL / c`，其中光程 `OPL = Σ n·L`；玻璃内按折射率累积，
  因此同一几何路径在玻璃中更慢。剖面外的路径也不会被“跳帧”。
- **脉冲光源**可设置脉宽 `τ` 与重复周期 `T`；**接收屏**可设置采集窗口
  （起点 + 宽度）。
- 脉冲列按稳态处理：窗口开始前若干周期的脉冲同样计入，窗口若开在一个脉冲
  中途，会保留该脉冲的剩余尾部，不会把“上一周期的尾巴”丢掉。
- 到达事件保留 `source`（哪个光源）与 `ray`（哪条追迹光线）两个标识，
  同一时刻、同一位置的多路光不会互相吞并；图表按来源分色，重合区间用
  混合色显示。

## 精确传播与时间分桶

同一批到达事件用两种估计器各自累积成 (到达时刻 × 屏上位置) 的联合分布：

| 估计器 | 做法 | 代价 |
| --- | --- | --- |
| 精确区间传播 `exact` | 每个脉冲区间与它覆盖的每个时间桶做重叠积分 | 每个脉冲约 2 个桶更新 |
| 时间分桶采样 `binned` | 整颗脉冲按中点落入单个时间桶 | 每个脉冲 1 次更新 |

两者总能量相同；差异就是“分桶把脉冲挪位”的代价。图表下方实时给出：

- 实测 L1 误差与保守上限 `2·Σ(power·duration)`（W·ps）；
- 时间桶宽（= 到达时刻不确定度）、位置桶宽（= 位置量化）；
- 两种估计器的实际单元更新次数；
- 桶宽小于脉宽时的明确警告（分桶会丢峰）。

判定使用**未量化**的事件统计（`eventStats`），绘图使用分桶网格，因此调整桶数
只会改变图像与报告的量化误差，不会改变任务通过与否。

## 资源边界：未知 ≠ 无信号

- 每条光线最多 32 次表面交互（`MAX_BOUNCES`）；用尽预算的光线记为 `unknown`
  并保留剩余功率，**不会**被当作“驶出场景”。
- 真正逃逸出场景的光线记为 `escaped`，这是可确认的“无信号”。
- 事件数（60 000）或单元更新数（3 000 000）触顶时，分析标记 `truncated`，
  界面与任务判定都会明确说明“结果未知”，绝不静默截断。
- 任务只要存在未知光线或截断，就不会判定为完成。

## 任务

第四个任务“同一时刻到达”要求两路脉冲经直射与绕行（两面镜 + 一块玻璃）后
在窗口内重合 ≥ 40 ps，且窗口内接收能量 ≥ 2000 W·ps。默认重复周期与两路光程差
不匹配，可通过改变重复周期或玻璃厚度/折射率使两路重合。

## 一致性与撤销

图表、光路动画、时间刻度尺与任务判定都取自同一个 `LabDocument` 与同一个
playhead：

- 播放头停在记录到达时刻时，动画中的光恰好触及接收屏（有测试锁定该不变量）。
- 撤销/重做栈保存整份文档快照，因此改变时间窗、玻璃折射率或估计方式后，
  一次撤销会同时恢复图表、动画与判定所用的时间基准。

## 结构

```
src/shared/         文档模型、几何、共享时间基准（timing.ts）
src/features/optics/光程追迹（trace.ts 携带 OPL 与飞行时间）、动画播放头
src/features/detector/联合分布分析（analysis.ts）、门控面板与图表
src/features/missions/任务预设、基于门控结果的判定
src/features/bench/ 画布、器件、撤销历史、本地存储（旧文档自动迁移）
tests/              物理与时间分析测试
```
